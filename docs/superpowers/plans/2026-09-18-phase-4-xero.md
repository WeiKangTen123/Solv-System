# Solv Expense Claims — Phase 4 (post to Xero) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finance connects the company's Xero organisation once (Custom Connection or OAuth, the same two methods as the Xero automation), and posts an approved expense report to Xero as one DRAFT ACCPAY bill payable to the claimant, with one line per report line, account codes chosen from the org's own chart of accounts by category, and the receipts attached. Nothing is sent until finance clicks Post; a dry run shows exactly what would be sent.

**Architecture:** The Xero automation's connection stack is ported with one change of scope — a connection belongs to the company, not to a user: `xero-utils.js` (retry, error parsing, scopes), `oauth-state.js`, `token-cache.js` (keyed by company id), `connect.js` (Custom Connection), `oauth.js` (auth-code flow), `reconnect.js`, `contacts.js`. New: `category-account.js` (Solv category names → the org's account names), `attachments.js` (each receipt as a ≤3 MB JPEG or PDF), `bills.js` (a pure `buildBill(payload, accounts, defaults)` plus `postReport(reportId, actor)`). Routes: `/api/xero/*` for the connection and `POST /api/reports/:id/post`.

**Decision fixed here (a change from the spec, stated):** the bill is raised in the company's base currency with each line's base amount, and the original currency, amount and rate go in the line description ("INR 43,131.36 × 0.01341"). A report can hold several currencies and rate dates; one bill in SGD whose lines equal the printed report is the only way the Xero figure and the report agree to the cent. `CurrencyRate` is therefore not needed.

**Tech Stack:** as before; `xero-node` 7 (already installed) for the Accounting API, `sharp` and the Phase 1 renderer for attachments.

In `connect.js` and `oauth.js` replace `getUserConfig(userId)` / `saveUserConfig` with `getCompanyConfig(companyId)` / `saveCompanyConfig`, and every `userId` parameter with `companyId`. Write `reconnect.js`:
  ```js
  // Empty token cache but credentials on file: reconnect by whichever method is active.
  async function reconnectXero(companyId) {
    const { getCompanyConfig } = require('../utils/users');
    const type = getCompanyConfig(companyId).XERO_CONNECTION_TYPE;
    return type === 'oauth' ? require('./oauth').reconnect(companyId) : require('./connect').autoConnect(companyId);
  }
  module.exports = { reconnectXero };
  ```
